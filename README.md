# 🚀 Projects:

### 🧠 Company Brain *(In Progress)*
AI-powered institutional memory platform for Auxilo Finserve. Built on RAG and PageIndex — lets employees query internal documents and get intelligent answers. Stack: FastAPI, MySQL, Groq API, React.

### 📨 DICE — Multi-Channel Messaging Platform *(Active)*
Internal messaging platform for sending WhatsApp, SMS, and Email at scale. Rebuilt with bulk campaign support, delivery tracking, AI template builder, and audience segmentation.
- 🐍 [DICE Python SDK](https://github.com/Tushar216-507/auxilo-dice-sdk) — `v1.0.0`
- 🐘 [DICE PHP SDK](https://github.com/Tushar216-507/auxilo-dice-sdk-php) — `v1.0.0`

### 🧾 Invoice Management System *(Active)*
Flask-based invoice system with vendor management, WhatsApp/email notifications via DICE, Excel export, and 2FA login. Integrated with DICE SDK for all notifications.

### 🤖 Auxilo AI Chatbot *(Completed)*
Full RAG chatbot using Flask, MySQL, Groq API, and React. Document upload, vector embeddings via nomic-embed-text, cosine similarity search, and dark-themed frontend.
